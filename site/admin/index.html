How it was made

The site began as one request in the Sovereign Website factory on 25 November 2026, from the text Lee-Elle supplied. sites.b filed it and started a dedicated keeper; factory.b created this repository and its address; design.b wrote the design brief; the keeper built five designs, in English and in Hebrew; design.b.rounds reviewed them with synthetic parents, twice.

For the full story, see the behind-the-scenes tour, the keeper's notes and the publishing runs.
